=========================================
Project : Smart Night Security System
=========================================

Components Used
---------------
1. Arduino UNO
2. Photoresistor (LDR)
3. Ultrasonic Sensor (HC-SR04)
4. LED
5. Piezo Buzzer
6. 10kΩ Resistor
7. 220Ω Resistor
8. Breadboard
9. Jumper Wires

Connections
-----------

Photoresistor (LDR)

One Leg -------------> Arduino 5V
Other Leg -----------> Arduino A0

10kΩ Resistor

One End -------------> Arduino A0
Other End -----------> Arduino GND

Ultrasonic Sensor

VCC -----------------> Arduino 5V
GND -----------------> Arduino GND
TRIG ----------------> Arduino D9
ECHO ----------------> Arduino D10

LED

Arduino D8 ----------> 220Ω Resistor
220Ω Resistor -------> LED Anode (Long Leg)
LED Cathode ---------> Arduino GND

Piezo Buzzer

Positive (+) --------> Arduino D7
Negative (-) --------> Arduino GND

Working
-------

Dark + Object within 15 cm

→ LED ON
→ Buzzer ON

Otherwise

→ LED OFF
→ Buzzer OFF
